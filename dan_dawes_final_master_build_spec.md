## 3. Signature Interactive Features & Executive Motion

### A. "The Loyalty Signal Wave" Hero Canvas

* Lightweight 60fps HTML5 `<canvas>` backdrop inside `#hero` rendering 3 translucent sine/Bezier wave ribbons (Amber Gold, Signal Teal, Soft White) + 28 moving data-point dots.

* **DPR-Safe Resize:** Always reset transform on resize using `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` (never compound `ctx.scale()`).

* **Lerped Mouse Interaction:** Cursor movement smoothly modulates wave amplitude and pulls nearby dots into alignment.

* **Accessibility:** Automatically renders a static frame under `prefers-reduced-motion: reduce`.

### B. Hairline Scroll-Progress Bar & Scroll Reveals

* Fixed `2px` Amber Gold-to-Teal progress bar pinned to the top of the viewport.

* Subtle `IntersectionObserver` scroll-reveal (`opacity` + `translateY(18px)`) on major editorial blocks, disabled under `prefers-reduced-motion: reduce`.

### C. Sequential Number Count-Up (Credibility Strip)

* Uses `tabular-nums` so digits never jitter horizontally.

* Triggers when entering viewport (`threshold: 0.25`) with staggered left-to-right delays and readable ease-out pacing:

  * `1× → 4×` (`duration: 1100ms`, `delay: 0ms`)

  * `1+ → 20+` (`duration: 1400ms`, `delay: 180ms`)

  * `0 → 1` (`duration: 650ms`, `delay: 360ms`)

  * `#1 → #39` (`duration: 1600ms`, `delay: 520ms`)

* Dark Harbor Navy glass modal (`max-h-[90vh]` with internal scroll on mobile, closes on `Esc` or backdrop click) containing:
